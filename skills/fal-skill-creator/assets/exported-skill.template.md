`fal` below is short for `uv run <this-skill-dir>/scripts/fal.py`. Without uv, run
`pip install "fal-client>=1.0,<2" httpx jsonschema` and use `python3 <this-skill-dir>/scripts/fal.py`.

## Generate

1. **Read `profile/prompting.md` first**: the key rules, the Inputs section (what reference media works) and the
   limitations. Tell the user up front when a request hits a limitation instead of paying for a retry.
2. **Pick the template** that fits the request and fill every slot from what the user asked for. Invent only what
   they left open, following the key rules. Pass an empty value (`--slot style=`) to drop a part that doesn't apply.
3. **Confirm first** when the request is vague, the output is video or 3D, or it's a batch: show the filled prompt,
   the key settings and the unit price in one message.
4. **Run it:**
   ```bash
   fal run --profile <this-skill-dir>/profile --template <name> --slot subject="…" --slot style="…" [--preset NAME] [--set key=value] [--label tag]
   ```
   Add `--dry-run` first to see the rendered prompt and final arguments. Local files: `--set image_url=@./file.png`.
   An earlier run's output: `--from last`, or `--set field=from:<run>#<kind>`. Variations: `--batch requests.jsonl`
   (one JSON object per line; `"$slots": {...}` changes slots per line).
5. **Check the output yourself** (open image files; read video and audio metadata in the manifest) against the
   request before reporting the file paths and the run id. If it misses, adjust slots or the template's wording
   using prompting.md, keep the seed (`--set seed=<manifest seed>`), and offer a rerun.

Exit codes: 2 means fix the arguments (`fal schema {{endpoint_id}}`, or the missing `--slot` it names). 4 means a key
problem (`references/auth.md`). 5 means fal returned an error. 6 means the job is still running:
`fal fetch <run_dir>`, and don't resubmit.

## Chaining

Outputs are saved in `./fal-outputs/<date>/<run_id>/` with a `manifest.json`. Other fal-* skills, and this one, can
consume it with `--from`. See `references/pipelines.md`.

## Maintenance

`fal profile refresh <this-skill-dir>/profile` re-fetches the schema and reports drift. `fal profile check
<this-skill-dir>/profile` re-checks the input guide. To update the runtime or the research, re-export from
fal-skill-creator with `--force`.
